# Remediation report — independent audit of commit `9be0d2c`

Scope: findings B1–B9 and the medium-severity items of the independent Codex/Astra audit. All work offline; **no paid model call, no deployment, no submission**. Each finding has a regression test in `tests/test_audit_regressions.py`; all 21 original regression tests were run against the audited implementation first and **all 21 failed** (reproduction), then pass after the fixes. Three further tests guard against over-correction (`test_gates_do_not_over_block_a_complete_verified_run`, `test_baseline_and_ablation_arms_never_submittable`, `test_b4_indel_equivalence_uses_identical_normalisation`).
