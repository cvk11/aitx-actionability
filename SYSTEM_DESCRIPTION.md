# System description (draft for the submission form — Tier 3)

> Draft text. Final numbers (models served, cost, run date) must be filled from `outputs/run_manifest.json` after the real run. No reports have been generated yet.

**Name:** aitx-actionability — evidence-ledger agentic pipeline for therapeutic actionability reports.

**Tier:** 3 (Unrestricted). **Base model:** Anthropic Claude Opus 5.5, exact model identifier `claude-opus-5-5` (adaptive thinking, effort `high`; verifier effort `medium`). Server-side refusal fallback (`fallbacks: "default"`) is enabled; the model that actually served every call is recorded, and any fallback is disclosed in the run manifest. Optional independent reviewer: Google Gemini `gemini-4-argon` (off by default; not used unless stated).

**Architecture.** One generalizable pipeline for every patient; no case-specific code, prompts or answers (enforced by an automated test).
1. *Deterministic molecular bootstrap (no LLM):* RefSeq transcript model from the NCBI feature table (exon/intron position, exon coding length and reading frame, PTC position, rule-based NMD prediction), VariantValidator nomenclature check, Ensembl VEP cross-check, ClinVar exact-HGVS match, ClinGen validity/dosage, gnomAD constraint, UniProt features at the residue, GeneReviews chapters, open trials.
2. *Interpretation agent:* disease, inheritance/zygosity fit, gene-level vs variant-specific mechanism with an explicit confidence label, missing clinical information, research plan.
3. *Three parallel agentic researchers* (Tier 1 / Tier 2 / Tier 3 sections) iterating over live tools: PubMed, Europe PMC (open-access full text), ClinVar, ClinicalTrials.gov API v2, openFDA/DailyMed labels, GeneReviews (official NCBI archive snapshot, dated), ClinGen, gnomAD, UniProt, ClinPGx, allow-listed authoritative pages. Every retrieved record enters an evidence ledger with access time and search coverage (first page vs. total hits). Models may cite only ledger keys; citation links are rendered from the ledger, links written by a model are stripped, and a report containing any link not traceable to the ledger is rejected.
4. *Deterministic rules* implementing the template's tier definitions: citations must exist in the ledger; retracted sources removed; trials must have an open ClinicalTrials.gov status and compatible age/sex on the live record, and non-recruiting states (not yet recruiting, by invitation, expanded access) are labelled as such and ranked below recruiting trials; ClinVar/VEP results are attributed to the patient's variant only on the same transcript version, or on another version when the GRCh38 allele is shown to be identical.
5. *Independent verification (fail closed):* PMID existence checks; live re-check of every cited trial (status, ages, sex, eligibility text); a separate Claude invocation judges every atomic claim and every full item statement against the retrieved source text. Every expected decision must be returned (one bounded re-verification for missing ones); undecided content is treated as unverified. Only items whose full statement is verified are rendered; verifier-suggested rewordings are never applied without re-verification. Off-label placement requires a verified human-treatment claim (intervention given to patients in the same gene/disease/variant context, with outcome); Existing Targeted requires a verified label/guideline claim; items failing these gates are moved to the tier their verified evidence supports (e.g., preclinical → Drug Repurposing) rather than discarded.
6. *Synthesis:* tier summary, conditional actions for missing data, Tier-3 outcome measures and ranking. Summary lines must point to verified items of the same tier and are verified like all other text; unverifiable lines are replaced by deterministic references to the verified items (no new clinical assertion) and unverifiable conditional actions/outcome measures are removed. A deterministic renderer writes the official template; structural QC mirrors the upload checks; a report enters the submission file only if all mandatory stages completed with complete verification decisions and no critical issue.

**Reproducibility.** Pinned model identifier and dependency versions; SHA-256 of every prompt, the official template/cases and the GeneReviews archive recorded per run; full audit trail (queries with timestamps, ledger, verdicts, rule events, cost). The Hugging Face Space runs the identical code at `/actionability_report` with no logging or storage of evaluation inputs/outputs. LLM outputs are not bit-for-bit deterministic and live records (e.g., trial status) can change between runs.

**Human editing:** none. Reports are produced end-to-end by the pipeline.
